# WIKI （本地浏览 + 单文件打包）

解决两个痛点："文档多了没法看"和"守则文件散落没人读"。纯观景台——**只读，不改任何文件**。

## 核心机制

### 本地浏览（serve）

```bash
node docs-site.js serve --port 4100
```

零依赖起一个只读 WIKI ：
- 左侧目录树三个分组：**◆ 守则**（AGENTS.md / CLAUDE.md / SOUL.md 等，自动发现、置顶）、**◇ 根文档**（README / CHANGELOG / ROADMAP…）、**▸ 文档**（`--dir` 可换目录，默认 docs/）
- 侧栏顶部有**搜索框**，按文件名和标题即输即滤
- `[[双链]]` 跳转：`[[characters]]`、`[[characters|角色表]]` 都认；普通 markdown 链接指向 .md 的也自动转内链
- **反向链接**：每篇文档底部列出"哪些文档引用了我"——设定改动前先看反链，知道会波及谁
- 死链的双链显示为虚线（目标不存在），一眼看出该修
- 正文右侧**本页目录**，滚动时当前章节跟着高亮；文末自动带**上一篇/下一篇**
- 顶栏有主页 / 返回（浏览历史栈）按钮；手机上侧栏收进汉堡菜单，右下角悬浮按钮弹出本页目录

### 配色三态

顶栏一键循环：**◐ 自动**（跟随系统，默认）→ **○ 白天**（白蓝）→ **● 夜间**（黑蓝）。
选择记在浏览器里（localStorage），serve 和 pack 产物都带。界面风格用几何符号不用 emoji。

### 单文件打包（pack）

```bash
node docs-site.js pack --out docs-site.html
```

全部文档（含守则）渲染后打成**一个 HTML 文件**，双链、反链、目录树、搜索、配色切换全保留，侧栏底部标注打包时间。发微信、传手机、离线看都行——给不装任何工具的合作者（如只管画画的美术）用。

### 收录规则

- 自动跳过：`.开头目录`、`_archive/`（归档区，配合安全红线）、`node_modules/`
- 图片显示为占位符（不内嵌，控制单文件体积）
- 渲染器支持：标题 / 粗斜体 / 行内代码 / 代码块 / 列表（嵌套）/ 表格 / 引用 / 分隔线；所有文本先转义再渲染，代码块里的 `#` 不会误判成标题
- **按语言收录**：如果一篇文档旁边有同名 `.zh.md`（如 `foo.md` + `foo.zh.md`），顶栏 EN/中 切换会决定侧栏里显示哪一份（en 显源文 `.md`，zh 显 `.zh.md`）。没有 `.zh.md` 配对的文档始终显源文。这遵循 indie-keeper"源文.md + 译文.zh.md 同目录"的双语约定；如果你仓库用别的多语言布局（如 `docs/en/` + `docs/zh/` 分目录，或没有译文），这个自动过滤也不会丢文件——最坏情况是两种语言都列出来，想关掉可以改 `scripts/commands/docs-site.js` 里的 `collect()` 函数。

## 建房流程

WIKI 没有状态、没有配置文件，随时可用：
1. 有文档就能跑，先 `serve` 给用户看一眼
2. 用户需要分发就 `pack`；产物 `docs-site.html` 建议加进 `.gitignore`（随时可重新生成，不必进版本库）

## AI 日常纪律

- 用户说"文档给我看看/发我一份"→ 优先想到 `pack`，别把十份 .md 一个个贴出来
- 写文档时多用 `[[双链]]` 连接相关文档——反链是免费攒出来的知识网
- 本工具只读；发现内容问题回档案室（truth.js）修，不在这里动手
